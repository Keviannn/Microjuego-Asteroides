# Microjuego Asteroids
Implementación del clásico juego Asteroids como proyecto inicial para la asignatura de Fundamentos de Vieojuegos hecho en Unity.

## Cómo se juega                                                               
El juego tiene controles de tanque, por lo que funciona con aceleraciones y giros.

| Acción | Teclas |                                                               
|---|---|                                                                         
| Acelerar / frenar | `↑` / `↓` (o `W` / `S`) |                                   
| Girar | `←` / `→` (o `A` / `D`) |                                               
| Disparar | `Espacio` |                                                          
| Pausar / reanudar | `Esc` o botón de pausa en pantalla |
